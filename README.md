## 🎮 What Is time-crisis-vr?

time-crisis-vr is a VR project that recreates the feel of Time Crisis on Meta Quest 3. It is a standalone experience, meaning the headset is the main device that runs the application. Your Windows computer is used to download the files and transfer them to the headset.

The project uses OpenXR, a VR standard that helps compatible applications run correctly on supported headsets. The gameplay focus is on aiming with a tracked pistol, ducking behind cover with your body, and shooting targets in a fast arcade-style flow. Because this is an experimental port based on spacestate1/namco22-decompile, it is aimed at users who want to try a work-in-progress VR version of a classic light-gun style game on Meta Quest 3.
